# EMS Logistics

Patient-facing website and interactive sample-data demo for planned dialysis transportation coordination in Houston.

Website: https://psxio.github.io/ems-logistics/
Demo: https://psxio.github.io/ems-logistics/demo.html

The demo links ride requests, Site Leads, recurring calendar trips, simulated calling, fictional center lookup and email campaign previews. Changes are stored in the visitor’s browser. All people, facilities, contact details and distances are fictional. No real booking, calling, dispatch or email delivery is connected. Do not enter real patient data.

The downloadable two-page PDF preserves the full planned scope.
